# Instrument fonts

The workbench self-hosts Instrument Sans and Instrument Serif from Google
Fonts. Both families are licensed under the SIL Open Font License 1.1:

- <https://fonts.google.com/specimen/Instrument+Sans>
- <https://fonts.google.com/specimen/Instrument+Serif>
- <https://scripts.sil.org/OFL>

The `.woff2` files here are the regular and italic faces used by
`webapp/static/style.css`. No font is loaded from a third-party CDN.
